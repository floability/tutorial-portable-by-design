# Portable by Design Tutorial

Welcome to the hands-on companion for **Portable by Design: Deploying Notebook-based Scientific Workflows across HPC Clusters**.

This tutorial introduces tools and techniques for building portable, reproducible scientific workflows with **TaskVine, Sciunit, and Floability**.

## Start here

Begin with [**Access and Setup**](01-access-and-setup/index.md). Live participants will connect to the prepared tutorial server. Self-managed participants will clone this repository and create a local environment.

## Tutorial path

1. Connect to or create the tutorial environment.
2. Build and run distributed workflows with TaskVine.
3. Capture reproducible executions with Sciunit.
4. Inspect and run portable workflows with Floability.
