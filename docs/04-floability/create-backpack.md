# Create and Run a Floability Backpack

**Session time:** 20 minutes

In this exercise, you will package workflow code into a backpack, complete its
required specifications, and run the result.

## Learning goals

- create the standard backpack directory structure;
- place the workflow entrypoint under `workflow/`;
- declare the direct software dependencies;
- add the required data and compute specifications; and
- validate the result by running the new backpack.

The starter workflow and exact construction path will be selected before the
exercise is finalized.
