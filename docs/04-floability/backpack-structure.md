# Structure of a Floability Backpack

**Session time:** 10 minutes

This section opens the backpack used in the first exercise and connects each
directory to a deployment responsibility.

## Learning goals

- locate the workflow entrypoint under `workflow/`;
- read the Conda specification under `software/`;
- understand optional data profiles and integrity information under `data/`;
- read worker and resource intent under `compute/`; and
- distinguish portable backpack specifications from site-specific overrides.

The walkthrough will use real files from the selected tutorial backpack.
