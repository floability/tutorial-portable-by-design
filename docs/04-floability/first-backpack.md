# Run Your First Backpack

**Session time:** 15 minutes

In this exercise, you will deploy an existing notebook backpack rather than
constructing one. This keeps the first run focused on the Floability execution
experience.

## Learning goals

- identify the root of an existing backpack;
- start it with `floability run --backpack ...`;
- open the JupyterLab URL created for the run;
- execute the notebook with TaskVine workers; and
- stop the interactive session cleanly.

The complete command sequence and selected tutorial backpack will be added
after the live infrastructure and example are finalized.
