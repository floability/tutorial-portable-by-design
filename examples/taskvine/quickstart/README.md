# TaskVine Quickstart

This is the first TaskVine example in the tutorial. It submits five word-count tasks that share a copy of *War and Peace* from Project Gutenberg.

Follow the participant instructions in [TaskVine Quickstart](../../../docs/02-taskvine/quickstart.md).

The program is adapted from the [Floability CLI TaskVine quickstart](https://github.com/floability/floability-cli/blob/main/example/taskvine-quickstart/workflow/taskvine-quickstart.py). The tutorial version assigns each manager the name `taskvine-quickstart-USERNAME` and prints the local worker command.
